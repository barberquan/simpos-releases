# SimPOS — bản cài Android (APK)

Repo này chỉ chứa file cài đặt Android của SimPOS, dùng trong lúc chờ phát hành trên Google Play.
Mã nguồn không nằm ở đây.

- **SimPOS Bán Hàng** (nhân viên & thu ngân): `SimPOS-BanHang.apk`
- **SimPOS Chủ Quán** (chủ quán & quản lý): `SimPOS-ChuQuan.apk`

Hướng dẫn cài và bản mới nhất: https://simpos.vn/android
